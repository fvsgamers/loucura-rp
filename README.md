# 💀 GTA V: Modo Loucura Ativado

Este script transforma o trânsito e os pedestres pacíficos de Los Santos em um pandemônio absoluto. 

### 🚨 O que este script faz?
* Transforma a vovozinha da esquina em uma atiradora de elite profissional armada com uma shotgun.
* Faz o motorista do ônibus adotar o estilo de direção "Mad Max".
* Garante que todo mundo se odeie, mas que todos odeiem **especialmente você**.
* Adiciona raios, trovões e um clima de "fim do mundo" porque caos sem uma boa iluminação dramática não tem graça.

**Requisito de sistema:** Boa sorte e um colete à prova de balas.
